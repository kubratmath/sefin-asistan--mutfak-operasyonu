# sefin-asistan--mutfak-operasyonu
"Şefin Asistanı: Mutfak Operasyonu", 6. sınıf öğrencilerinin kesir, ondalık ve yüzde konularını restoran mutfağında deneyimlediği eğitsel bir matematik simülasyonudur. Süre kısıtsız yapısı, dijital tartı kullanımı ve Şef'in anlık yönlendirmeleriyle hatalardan öğrenmeyi destekler,Michelin yıldızlarıyla eğlendirir.
